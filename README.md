# Women Therapist Near Me — Inline CSS/JS Foldered Build

Base URL: https://lucknow-massage-spa.github.io/women-therapist-near-me/

## Folder structure
- `services/` — service pages and service directory index
- `areas/` — 100 local area pages and area directory index
- `area-services/` — 300 area + service pages and directory index
- `blog/` — 150 blog pages and blog index
- `faq/` — 50 FAQ pages and FAQ index
- `guides/` — 50 guide pages and guide index
- `contact/` — contact and booking pages
- `legal/` — privacy policy and terms
- `assets/images/` — shared local images/icons
- `assets/source-backup/` — backup copies of the original shared CSS and JS

## Important
Every HTML page contains the complete CSS and JavaScript inside that file. You can upload or replace one page inside its matching folder without separately uploading CSS or JS. Keep `assets/images/` available because pages use local SVG images/icons from this folder.

Extract this ZIP and upload the contents (not the ZIP itself) to the root of the GitHub repository.
